# Factory Control · install artifacts (beta)

Public mirror of the **v0.0.1** release assets from the private [`aguvoda/factory-control`](https://github.com/aguvoda/factory-control) repository so anyone can install without GitHub auth.

## Install (anonymous)

```bash
npx --yes https://github.com/matiaspakua/factory-control-install/releases/download/v0.0.1/factory-core-0.0.1.tgz init
npx --yes https://github.com/matiaspakua/factory-control-install/releases/download/v0.0.1/factory-plugin-0.0.1.tgz install
```

Source of truth and development: `aguvoda/factory-control` (private). This repo only hosts downloadable tarballs/VSIX.
